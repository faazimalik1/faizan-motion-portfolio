# Faizan Malik Motion Portfolio

Upload every file and folder in this directory to the root of a GitHub Pages repository.

The site is a static HTML/CSS/JavaScript build. It uses CDN-loaded GSAP, ScrollTrigger, Lenis, and SplitType for the cinematic motion layer. Vimeo embeds and the local showreel remain in the existing asset folders.

## Included interactions

- Lenis smooth scrolling
- GSAP scroll reveals and pinned-style media movement
- Masked heading reveals
- Perspective and tilt project cards
- Magnetic buttons
- Desktop custom cursor states
- Animated grids, ambient light, orbit rings, and energy lines
- Scroll-triggered showreel autoplay and pause
- Graphic design gallery and UI/UX case study link
- Animated counters, timeline, toolkit cards, contact states, resume CTA
- Mobile navigation and reduced-motion support

Keep the existing relative folder structure when uploading. The site entry point is `index.html`.
